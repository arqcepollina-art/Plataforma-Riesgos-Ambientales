# GeoRiesgo Guatemala

Plataforma de tamizaje de amenazas naturales por polígono de proyecto. Cargue un KMZ, KML, GeoJSON o coordenadas (GTM, WGS84, UTM), visualice el polígono sobre los mapas de inundaciones, deslizamientos, sequía, heladas y proximidad volcánica, y descargue una ficha PDF con el nivel de exposición.

Fuente cartográfica: Sistema de Información Estratégica (SIE). Resolución de análisis: 100 m. Herramienta de tamizaje; no sustituye estudios técnicos específicos ni evaluaciones oficiales de CONRED, INSIVUMEH o MARN.
